## Implemented safeguard

`backend/pkg/config/config.go` recognizes `OTP_DELIVERY_PROVIDER` as a fallback behind the existing `SMS_PROVIDER` and `OTP_PROVIDER`. If **any** of those variables requests `fcm_test` or `mock`, startup rejects the configuration in every environment until an actual isolated, reviewed provider is implemented.
