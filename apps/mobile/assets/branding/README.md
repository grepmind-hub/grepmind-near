# Grepmind Near launcher icon concepts

- `launcher_icon_concepts_v1.png`: original six shop and service discovery concepts.
- `launcher_icon_concepts_abstract_gm.png`: six abstract, non-letterform GM-inspired concepts.
- `launcher_icon_option_1.png`: selected option 1 from the second sheet, prepared as the 1024px launcher icon master.

The selected master is rendered into Android's standard mipmap densities at `android/app/src/main/res/mipmap-*/ic_launcher.png`. The manifest already references `@mipmap/ic_launcher`; no Flutter or launcher-icon dependency was added.
